Minesweeper

A Minesweeper game with a rule-based solver and a later JEV integration.

Open product ↗GitHub ↗

RECORDED FROM THE ORIGINAL PRODUCT

Run it yourself

Clone the repository and run python3 -m http.server 8000 from its root. Open localhost:8000. No build or account is required.

Open the game, then click Activate Ai to run the original solver. The JEV integration is on its separate branch.

Built with

JavaScript, p5.js, HTML, and CSS. The p5 libraries are included in the repository.

Status

An earlier learning project, preserved with its original rendering and behavior. The same recording is used in the README and portfolio.
